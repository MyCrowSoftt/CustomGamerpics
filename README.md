Fun exploit I found about 3 years ago to allow uploading of custom gamer pictures.

When this was originally discovered it was possible to do it remotely to other users by changing the XUID in the storage url, this is apparently still possible even after I reported it to MSRC and they confirmed it was fixed but not 100% sure.

The current method used in a lot of tools done it the same way I did originally - through the avatar editor... not anymore 💅

This has been added to many tools over the years but most do it the annoying way mentioned about (Except Superiority 😉)

For this to work, make sure to have your current gamer picture set to one of your avatar, can be done in the avatar editor.

Once you have ran the code in the Gamerpic.cpp you will need to delete and redownload your account (Sometimes it can take around 24-72 hours to update - can sometimes be fixed by using a VPN in another country)
